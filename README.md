# SnapClass

An AI-powered smart attendance management system that automates classroom attendance using **Facial Recognition** and **Voice Recognition** technologies.

SnapClass aims to provide a secure, efficient, and contactless attendance solution for modern classrooms while demonstrating the practical use of Artificial 
Intelligence in education.

---

# 🚀 Features

* 🎭 Face-based student authentication
* 🎙️ Voice-based attendance verification
* 👤 Biometric student enrollment
* 📊 Automated attendance tracking and logging
* 📁 Attendance dashboard for record management
* 🌐 Modern and responsive web interface
* 🔒 Secure and efficient attendance system

# 🧠 How SnapClass Works

## Step 1: Student Enrollment

* Students register their facial data and voice samples.
* Biometric information is securely stored in the database.

## Step 2: Face Authentication

* The camera captures the student's face.
* Face recognition verifies identity using trained AI models.

## Step 3: Voice Verification

* The system records a short voice sample.
* Voice recognition confirms the student's identity.

## Step 4: Attendance Logging

* Once verification is successful, attendance is automatically marked.
* Attendance records are stored and displayed on the dashboard.
